# 遥控运输车端代码（归档片段）

> **重要：本目录不是完整的遥控车固件。** 省赛归档时只保留了调试阶段的代码片段，完整的无线遥控、机械臂与 OLED 显示逻辑未包含在内。

## 已归档内容

| 文件 | 内容 |
| --- | --- |
| `src/main.cpp` | 单路传感器触发示例：读取 A0，低电平连续确认后通过串口打印 `#` |
| `lib/rc/rc.cpp` | 四路摇杆模拟量读取函数（`Left_y` / `Left_x` / `Right_x` / `Right_y`） |
| `lib/nrf24L01/nrf24l01.cpp` | 占位代码：把 4 个模拟引脚设为输入并初始化串口，**未实现 NRF24L01 寄存器驱动** |
| `lib/nrf24L01/nrf2401.h` | 空头文件 |
| `lib/SoftwareSerial/` | Arduino 软件串口库（第三方） |
| `lib/pinout/pinout.h` | 摇杆与蓝牙引脚定义 |

## 引脚定义

| 功能 | 引脚 |
| --- | --- |
| 左摇杆纵向 | A0 |
| 左摇杆横向 | A1 |
| 右摇杆横向 | A2 |
| 右摇杆纵向 | A3 |
| 蓝牙 RX / TX | D0 / D1 |

## 编译

```bash
cd remote-control-robot
pio run
pio run -t upload
```

开发环境为 PlatformIO + Arduino Uno。由于代码只是片段，烧录后仅能验证摇杆采样与单路传感器触发，不能直接遥控整车。

## 完整方案参考

遥控车的机械结构、4 轴机械臂、OpenMV 识别与 2.4G 通信方案见：

- [../docs/design-report.md](../docs/design-report.md) 第 2、3 章；
- [../README.md](../README.md) 的「遥控运输车端代码说明」。

若要补全固件，建议按以下顺序实现：

1. NRF24L01 初始化、通道 / 地址 / 速率配置；
2. 摇杆采样与死区处理；
3. 电机差速混控与限速 / 缓启动；
4. 4 轴机械臂舵机控制与动作序列；
5. OLED 状态显示；
6. 与自主车的任务信息协议。
